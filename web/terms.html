آخرین به‌روزرسانی: شهریور ۱۴۰۴

۱. ماهیت سرویس

دیوار واچر یک سرویس اطلاع‌رسانی آگهی است که بر اساس فیلترهای شما، آگهی‌های تازه‌ی دیوار را پایش و به تلگرام می‌فرستد. این سرویس وابسته به در دسترس بودن منابع عمومی/غیررسمی دیوار است و تضمین دسترسی دائمی به API دیوار نمی‌دهد.

۲. حساب کاربری

ثبت‌نام از طریق ربات تلگرام انجام می‌شود. حفظ یوزرنیم و رمز پنل بر عهدهٔ شماست. هر حساب فقط برای استفادهٔ شخصی/کسب‌وکار خودتان است.

۳. اشتراک و پرداخت

پلن آزمایشی رایگان و محدود است. پلن‌های پایه و حرفه‌ای ماهانه هستند و با کارت‌به‌کارت + تأیید پشتیبانی فعال می‌شوند. مبلغ و جزئیات در صفحهٔ قیمت اعلام می‌شود.

۴. محدودیت‌ها و توقف

ممکن است به‌دلیل محدودیت دیوار، اختلال شبکه، یا سوءاستفاده، پایش موقتاً قطع یا کند شود. در صورت نقض قوانین یا فشار غیرعادی روی سرویس، حساب می‌تواند تعلیق شود.

۵. مسئولیت

تصمیم‌گیری روی آگهی‌ها و معاملات بر عهدهٔ شماست. دیوار واچر بابت از دست رفتن فرصت معامله، خطاهای دادهٔ شخص ثالث، یا قطع موقت سرویس مسئولیتی فراتر از تمدید متناسب اشتراک ندارد.

۶. داده و حریم

اطلاعات حساب، فیلترها و کش آگهی برای ارائهٔ سرویس نگه داشته می‌شود. کلید API داخلی افشا نمی‌شود؛ مستندات API فقط برای پلن حرفه‌ای است.
